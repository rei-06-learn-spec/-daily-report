## 2026-05-18 (Sprint 2 Day 1)

### 今日学んだこと
- 状態管理リファクタの本質は「定数をuseStateに乗せることでReactが変化を検知できるようにする」こと
- Hookはコンポーネントの中でしか使えない。`createRoot().render()` の中には書けない
- カスタムフックはコンポーネントからロジックを切り出して再利用するためのもの
- ジェネリクス`<T>`は「型を引数として受け取る」仕組みで、useLocalStorageをどんな型でも使い回せるようにする
- `BookCard` の Props は配列（`Book[]`）ではなく1冊（`Book`）で受け取る。BookListがmap()で分解して渡す
- 同じデータを2か所で管理しない。BookDetail用に別stateを作らず、同じ `books` を渡して `.find()` で絞り込む
- `useLocalStorage` の return に `as const` が必要。ないとTypeScriptがタプルではなく配列と解釈してしまう
- `localStorage` は文字列しか保存できないので `JSON.stringify` / `JSON.parse` で変換が必要

### 詰まったこと
- `localStorage.setItem` の引数の順番を逆に書いた → `setItem(キー名, 保存する値)` の順番
- `JSON.stringify("value")` と引用符をつけてしまった → 変数の `value` を渡す

### 今日実装したこと
- `src/App.tsx` 作成（useState → useLocalStorage への置き換え）
- `src/hooks/useLocalStorage.ts` 作成
  - 初回: localStorageにデータがあれば復元、なければinitialValueを使う
  - 変更時: useEffectでlocalStorageに自動保存
- `BookList.tsx` / `BookCard.tsx` を Props 経由でデータを受け取る構造に変更
- `BookDetail.tsx` も同じ `books` を受け取り `.find()` で1冊を特定する構造に変更

### データの流れ（今日覚えた設計）
```
App（books: Book[] を useLocalStorage で管理）
  ├── BookList に books を渡す → map で BookCard を1枚ずつ表示
  └── BookDetail に books を渡す → find で1冊を特定して表示
```
